Null kontrolü tüketiciye güvenli tip verir ve yanlış yerleşimi erken gösterir. React 19’da `<FavoritesContext value={...}>` doğrudan provider sözdizimidir. Proje görevi localStorage ve toggle davranışını ekleyecek.

## Alternatif ve tuzak

Varsayılan boş dizi provider eksikliğini gizler. Null kontrolü hem TypeScript tipini daraltır hem kurulumu yanlış yapan geliştiriciye açık hata verir.
