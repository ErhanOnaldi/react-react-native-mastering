## Neden böyle?

`movie.id` API verisinden gelen kalıcı kimliktir. Index veya rastgele key, sıra değiştiğinde satır kimliğini bozabilir. Boş durum mesajı yanlışlıkla kaybolmuş içerik izlenimini önler. `map` yeni görünümü üretir, props dizisini değiştirmez. Sonraki görev bu kimliğin input durumunu nasıl koruduğunu gösterecek.
