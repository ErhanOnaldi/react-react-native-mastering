# Cache belirtilerini ayıkla

:::pain[Problem]
Komedi seçili ama aksiyon filmleri duruyor. Verilemeyen puan ekranda kalıyor; “Puanladıklarım” ise başarılı değişiklikten sonra bile eski.
:::

Bu atölyede yöntem verilmez. Önce görünen belirtiyi yeniden üret, veri kimliğini ve güncelleme akışını kendin izle; ipuçlarını sıkışınca aç.

Görevler: tür değişince liste aynı, puan geri alınamıyor.
