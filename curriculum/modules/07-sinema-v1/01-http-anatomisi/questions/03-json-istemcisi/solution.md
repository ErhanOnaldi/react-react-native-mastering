`fetch` bir 404 cevabı alınca `Response` döndürür; `ok` kontrolü yapılmazsa hata verisi başarı verisiymiş gibi üst katmana geçer. Hata mesajındaki durum kodu 401, 404 ve 500 gibi cevapları ayırt etmeyi sağlar. 204 başarılıdır fakat JSON içermez. Ağ hatasında ayrıca HTTP durumu üretmemek önemlidir: sunucuya ulaşılamamış olabilir.
